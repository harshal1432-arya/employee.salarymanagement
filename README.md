# Employee Salary Management System

## 📌 Project Description

Employee Salary Management System is a Python-based application used to manage employee information and salaries.

The project uses Python, Tkinter, and MySQL to provide a simple and user-friendly employee management system.

## ✨ Features

- Add Employee
- View Employees
- Update Employee Salary
- Delete Employee
- Search Employee
- Salary Statistics
- Show All Employees
- MySQL Database Integration
- Graphical User Interface using Tkinter

## 🛠️ Technologies Used

- Python
- Tkinter
- MySQL
- MySQL Connector for Python
- VS Code
